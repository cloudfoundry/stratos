[Features]
- Every tab of an application, space, organization and Cloud Foundry page
  has a **CF CLI** menu with the cf commands that match the tab, names
  filled in. Choosing a command copies it to the clipboard; the menu never
  runs anything. Its last entry, **CF CLI All**, opens the full command
  page for that level, which is the former CLI Info page with its commands
  grouped by tab. The CLI Info buttons and the application summary's
  "CLI Info" link are replaced by the menu.
- The CF CLI All page of a Cloud Foundry, an organization or a space shows
  the commands of that level only; it used to show organization and space
  commands at every level. Its rename commands are shown to every user,
  since the page only shows commands.

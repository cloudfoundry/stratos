- Angular dependency updates:

| Component                     | From   | To     |
|-------------------------------|--------|--------|
| Angular framework             | 22.1.7 | 22.2.0 |
| Angular CLI and build tooling | 22.1.8 | 22.2.0 |
| Analog Vitest plugin          | 2.7.2  | 2.7.5  |

- Analog 2.7.2 failed on Angular 22.2 with `cache.has is not a function`
  (analogjs/analog#2575), because 22.2 changed the internal cache the
  plugin relies on. 2.7.3 carries the fix, and 2.7.5 stops starting idle
  Angular worker threads up front (analogjs/analog#2581), so unit tests
  and production builds share a single `@angular/build` 22.2.0.

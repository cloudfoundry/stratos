- Dependency updates: the Angular framework from 22.1.7 to 22.2.0, with
  the Angular CLI and build tooling from 22.1.8 to 22.2.0. The
  `@angular/build` copy that the Analog Vitest plugin loads stays on
  22.1.7: Analog 2.7.2 fails on 22.2.0 with `cache.has is not a
  function` (analogjs/analog#2575), because Angular 22.2 changed the
  internal cache the plugin relies on. The application builder carries
  its own 22.2.0 copy, so production builds use 22.2.0 throughout. The
  held copy is pinned in the root manifest and excluded from Dependabot
  until an Analog release supports 22.2.
